Watching grpc-markup parse

Seven markup formats land on one shared block vocabulary. Pick a format (or let the server sniff it), upload or paste a document, and the same TextBlock, TableRow and Cue events stream back whichever source wrote them. One HTTP request carries the document up while events come back down, the same shape as the gRPC call underneath.
